# Exemptions for scripts/check_ast_inventory.py.
#
# Format:  <check>:<name>  <reason>
#
# A reason is required, and a stale entry -- one naming something that is no
# longer a finding -- is an error. Both rules exist so this file stays a list
# of decisions somebody made, rather than a list of things nobody has looked
# at since. `python3 scripts/check_ast_inventory.py --list` prints every
# finding, allowlisted or not.

# --- producers -------------------------------------------------------------

producers:AssocData  Reserved extension hook, not a parser product. ScopeChild.assocData exists so a consumer can attach its own data to any node; the parser never sets it, and there is nothing for it to build.
producers:MonitorActivityLabeledStmt  Abstract base kept for API stability. Its one subclass, MonitorActivityEventually, became a MonitorActivityLabeledScope when compound activity statements became scopes (symbol-resolution plan WS4.1), so nothing derives from it or constructs it.

# --- symtree ---------------------------------------------------------------
#
# Group 1: activity and monitor scopes. Not reached through accept():
# TaskBuildSymbolTree::buildActivityScopeChild builds every activity scope --
# block or compound statement -- directly, pushing it before its bodies are
# walked (symbol-resolution plan WS4.1). Select branches and match choices
# are walked as bodies of their statement, which is pushed. If anything starts
# accepting one of these with an enclosing scope current, the bodies'
# declarations land there, and this check will not say so -- hence the reason
# naming the function.

symtree:ActivityAtomicBlock  Not reached by accept: built by TaskBuildSymbolTree::buildActivityScopeChild, with the statement pushed while its body is walked.
symtree:ActivityForeach  Not reached by accept: built by TaskBuildSymbolTree::buildActivityScopeChild, with the statement pushed while its body is walked.
symtree:ActivityIfElse  Not reached by accept: built by TaskBuildSymbolTree::buildActivityScopeChild, with the statement pushed while its bodies are walked.
symtree:ActivityMatchChoice  Not reached by accept: walked as a body of its ActivityMatch by TaskBuildSymbolTree::buildActivityScope.
symtree:ActivityRepeatCount  Not reached by accept: built by TaskBuildSymbolTree::buildActivityScopeChild, with the statement pushed while its body is walked.
symtree:ActivityRepeatWhile  Not reached by accept: built by TaskBuildSymbolTree::buildActivityScopeChild, with the statement pushed while its body is walked.
symtree:ActivityReplicate  Not reached by accept: built by TaskBuildSymbolTree::buildActivityScopeChild, with the statement pushed while its body is walked.
symtree:ActivitySelectBranch  Not reached by accept: walked as a body of its ActivitySelect by TaskBuildSymbolTree::buildActivityScope.
symtree:MonitorActivityEventually  Not reached by accept: built by TaskBuildSymbolTree::buildActivityScopeChild, with the statement pushed while its body is walked.

# Group 2: not reached. The enclosing visitor adds its node and stops, so
# these are never walked while a symbol scope is current. Each names the
# visitor that makes that true -- if that visitor starts descending, the
# entry here is wrong and this check will not say so, which is why the reason
# names it.

symtree:CovergroupCoverpoint  Not reached: TaskBuildSymbolTree::visitCovergroup and visitCovergroupType add the node and stop. A coverpoint name is not resolved through the symbol table.
symtree:CovergroupCross  Not reached: TaskBuildSymbolTree::visitCovergroup and visitCovergroupType add the node and stop. A cross name is not resolved through the symbol table.
symtree:ProceduralStmtMatchChoice  Not reached: TaskBuildSymbolTree::visitProceduralStmtMatch does not descend.

# Group 3: the symbol tree itself. These are what TaskBuildSymbolTree
# produces, never what it is given, so the walk this check warns about does
# not happen to them.

symtree:RootSymbolScope  Symbol-tree node: output of TaskBuildSymbolTree, never input to it.
symtree:ScopeChildRef  Symbol-tree node: output of TaskBuildSymbolTree, never input to it.
symtree:SymbolChildrenScope  Symbol-tree node: output of TaskBuildSymbolTree, never input to it.
symtree:SymbolFunctionScope  Symbol-tree node: output of TaskBuildSymbolTree, never input to it.
